# 公开清单与不公开标签的一票否决

用户需要按标签正选、按标签反选，并逐条分享或取消分享，最终形成一份可发布的公开清单。完整收藏库默认私有；公开规则是允许导出的范围，不是网站页面上的显示过滤。

首版提供三种基础模式：仅逐条手动选择（默认）；包含指定标签再排除指定标签；全部收藏减去指定标签（需主动切换）。包含列表和排除列表内部都按任意标签匹配。空的包含列表选中零条，不隐式转换为全部。

每条收藏可选择跟随规则、手动公开或手动私有。用户后续明确修订 Q41：不公开标签具有一票否决权，任何条目只要命中排除标签就不得公开，手动公开也不能越过。Q47 明确未设置公开性的标签保持中立，不因未被加入公开列表就成为排除标签。

计算顺序如下，第一条适用规则决定结果：

1. 位于回收站：不公开。
2. 含任意明确设置为不公开的标签：不公开。
3. 条目手动设为私有：不公开。
4. 条目手动设为公开：公开。
5. 其余条目跟随当前基础模式：手动模式不公开；包含模式需命中至少一个包含标签；反选模式公开。

例如包含列表为 rust、排除列表为 private：rust＋tool 可公开（tool 中立）；rust＋private 不公开；只有 tool 的条目可经手动公开进入清单；含 private 的条目即使手动公开也不得进入。相同标签若同时出现在包含和排除列表中，排除生效。

界面显示最终清单、数量和每项入选或被排除的原因。保存规则前预览增加与移除项，明确指出阻止公开的标签；批量操作复用逐条规则，标签改名不改变规则引用的标签身份。删除或合并被规则引用的标签时必须检查公开范围变化，不能让失效引用默默扩大公开集合。

启用标签规则后，新收藏、AI 或人工标签变化会自动重算清单，下一次成功部署后更新网站，无需逐条二次审批。此行为在启用时告知。条目手动私有和排除标签始终可以阻止公开。链接失效状态不参与这一选择：已入选的失效条目仍可发布，网站另提供隐藏筛选。

当前公开清单与上次成功部署的清单分别显示；取消公开尚未成功部署时不能声称已从网站撤回。发布仍只包含字段白名单，并使用已确定的临时 Actions 产物路径。

Q40、Q42 已接受，Q41 的逐条选择高于排除规则已由用户后续强调替换，Q47 确认中立标签。此决定接受标签自动变化可能扩大或缩小公开范围的行为，同时保留明确排除的硬边界。
