# 按编辑、同步与发布用途选择数据形式

插件本地使用 IndexedDB 按记录保存；私有 GitHub 仓库保存版本化 JSON/JSONL 快照；公开网站使用字段白名单生成紧凑 JSON，再以 gzip 压缩并由浏览器原生解压。三种表示使用共同数据契约，但不要求物理格式完全相同。

选择文本作为私有同步格式是为了检查变更和排错；并发合并由应用实现，不依赖文本或 Git 自动解决业务冲突。公开数据可重新生成，优先缩减下载体积；旧版数据测试约缩减 74%，不把这一结果当作 V2 的大小预测。首版不引入浏览器 SQLite、自定义二进制或整库压缩的本地可编辑缓存。
