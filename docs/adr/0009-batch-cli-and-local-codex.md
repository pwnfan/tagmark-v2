# 通过一次性 CLI 执行任务，以本机 Codex 调试 AI

TagMark CLI 一次读取已同步数据、选取待处理项、调用相应服务、校验并保护人工修订、合并写回后退出。执行进度保存在数据状态中，定时由外部调度器启动同一能力。目标中的定时任务由 GitHub Actions 运行，本机 CLI 用于手动执行和调试，无需 TagMark 在用户 PC 常驻。

本地 AI 调试采用 Rust CLI 启动 `codex exec` 子进程，传入允许的内容及共同规则，读取结构化结果后由 TagMark 校验和保存。先使用程序内的后端调用边界，不建立 HTTP 包装服务；只有确实出现其他 HTTP 客户端需求时再评估。使用此后端需要本机已有可用 Codex，而 TagMark 自身的独立分发要求不变。

GitHub 元信息由程序直接调用 GitHub API，能够与 AI 任务独立执行。GitHub-hosted Actions 不会自动访问用户 PC 的 Codex 进程或登录状态；云端 AI 需要配置该环境能使用的模型服务及认证。

用户提供 DeepSeek 官方 API 作为首个 HTTP 调试目标，指定 `deepseek-flash`。以 20 条代表性收藏对照本机 Codex，验证分类、定义和中英文译文，并记录质量、耗时及 token。DeepSeek 本次调试总预算上限为人民币 2 元，所有重试都计入；不能按轮次重复获得预算，也不自行切换更贵模型。长期模型和自动任务月预算由样本结果决定。

本机 Codex 与 HTTP 后端共用任务输入、完整 AI 生成政策、返回结构及程序校验，政策覆盖分类、命名、定义、打标规则及翻译等全部实际生成内容。这项选择不承诺两种模型的质量或输出能力完全相同；费用限制针对本项目发出的 DeepSeek 调试请求，不替其它应用控制整个账户的消费。
