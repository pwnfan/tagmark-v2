# 私有收藏库与公开展示分离

首版是单人维护收藏库的开源工具，其他用户各自部署自己的实例。完整收藏库及标签定义默认私有，独立网站仅展示用户明确选择公开的部分；桌面 Chrome 插件承担录入和编辑，首版不要求手机或普通网页编辑。

公开选择由用户决定，选为公开后按字段白名单自动更新网站：URL、标题、所用标签的显示名称及简短定义、公开 GitHub 元信息，以及链接状态、简短原因和最近检查时间。只发布公开收藏使用的标签；用户备注、正文摘录、打标规则及 AI 处理记录保持私有。

公开选择支持仅手动、标签包含后排除、全部减去排除标签三种模式；条目可跟随规则、手动公开或手动私有。明确不公开的标签拥有一票否决权，手动公开也不能越过；未设置的标签中立。规则保存前预览清单与变化，标签变化后自动重算并在下一次成功部署更新。完整规则见 [ADR 0013](0013-publication-selection-and-exclusion-veto.md)。

链接失效状态独立标记，不因失效删除收藏或自动取消公开。已公开的失效收藏仍默认在分享网站显示，网站提供隐藏失效收藏的筛选；四种状态、人工覆盖和复查策略已在 [ADR 0015](0015-link-availability-and-rechecks.md) 确定。

改回私有后，在下一次成功发布时移除该条目及不再需要的标签信息。网站撤回不保证收回第三方已保存的副本。这样保留个人分享网站，又使公开输出与完整收藏库有明确边界；用户需要接受发布延迟。

默认私有不等于只能在本机处理。用户允许将主动收藏页面的标题、简介、可提取的正文摘录及公开 GitHub README 交给自己配置的模型服务；不采集浏览历史、Cookie 或私人备注，正文发送可关闭，单条敏感收藏可跳过 AI。
