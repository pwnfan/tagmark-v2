# 用统一英文语义支撑多语言标签

每个标签具有一个英文标准名和一份英文原始定义，其他语言保存对应显示名和定义译文，语言切换不改变标签身份。首版完整支持英文和简体中文的插件界面、网站界面、标签名称和定义。

首版采用平面标签，不建立父子分类树。标签以稳定身份被引用，可由用户改名或合并；旧名、同义词和译名均可用于检索同一标签。改名不产生新的标签，合并遇到定义或人工设置冲突时由用户处理。

标签以资源的主题、用途和类型为依据，不因资源偶然使用某种实现技术就给它添加该技术标签；GitHub 实现语言另行筛选。新生成的标签信息区分面向人的简短释义和用于判断适用范围的打标规则，后者包含适用、排除条件及少量例子。

英文原文变化后，自动更新未经人工修订的译文；人工修订过的译文保留并标记为需要复核。保护按语言字段生效，修改中文译文不会冻结整个标签。缺失译文时回退显示英文。

相比各语言独立创建标签或只写百科说明，这样可以让人和 AI 对同一个标签采用一致含义。代价是需要记录译文所依据的英文版本，并让用户能发现和复核已过期的人工译文。
