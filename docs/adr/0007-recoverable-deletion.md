# 可恢复删除并保留删除后的离线修改

收藏删除后进入回收站，首版不自动清空。若另一台离线设备随后同步了对该条目的修改，条目维持删除状态，同时保留修改供用户选择恢复，不能因为迟到的编辑而自动重新出现。

用户可以导出整个 V2 收藏库作为备份，包含收藏、标签、译文、人工修订保护、回收站和处理进度，不含密钥。整库备份恢复到新的空实例，再由用户切换使用；首版不覆盖当前实例，也不合并两个已有收藏库。回收站中的单条恢复仍在原实例完成。

恢复和同步需要保留条目身份、人工修订保护及删除信息；这属于 V2 自身的数据恢复能力，不包含已移出首版范围的 V1 数据导入。

选择该方案是为了在多设备编辑下避免丢失内容或意外复活。代价是回收站占用存储，并需要用户处理删除与离线编辑的冲突；彻底清理及自动保留期限留待实际使用后决定。
