# 完整 URL 的标准序列化结果决定重复收藏

首版收藏 HTTP(S) 网页，以 WHATWG URL 解析后的完整序列化结果判定重复。协议、查询串和片段参与比较；HTTP/HTTPS、`#aaa/#bbb`、路径大小写、查询参数顺序及非根路径末尾斜杠的差异均保留。协议和域名大小写、默认端口、空根路径及标准路径点段由解析器统一，不依据重定向、网页内容或 canonical 标签自动合并。

这样会保留一部分实际内容相同的网址，但避免错误合并前端路由、查询参数或协议所表示的不同页面。重复收藏打开现有条目并保留人工修改；条目使用独立稳定 ID，网址改变不改变身份，键碰撞需处理冲突。具体边界样例见[数据与网址设计](../data-and-url-design.md)，Rust 与 Chrome 必须通过共同样例。
