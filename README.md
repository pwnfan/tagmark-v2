# TagMark V2

单人自部署的收藏管理工具：Chrome 插件负责收藏和整理，Rust CLI 执行 AI 分类与定期维护，完整收藏库在私有 GitHub 仓库同步，选定内容通过独立 Pages 网站分享。

当前处于开发规划阶段，尚无可使用的产品发行版。已确认的范围见 [Spec #1](https://github.com/pwnfan/tagmark-v2/issues/1)；任务在本仓库的 [GitHub Issues](https://github.com/pwnfan/tagmark-v2/issues) 跟踪。
